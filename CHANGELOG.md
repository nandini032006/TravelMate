# TravelMate Beta

## Version 0.9.0-beta

**Release Date:** 2026-06-02

### Features

- Multimodal Transit Planning (Bus, Metro, MMTS)
- RTC Bus Routing — 1,099+ Hyderabad routes
- Metro Routing — Hyderabad Metro Red, Blue, Green lines
- MMTS Routing — Suburban rail integration
- RidePool Beta — Community carpooling with dynamic matching
- Hyderabad Mobility Analytics — Area-level traffic, crowd, and transit scores
- Safety Analysis — Route risk zone detection
- Live Traffic Integration — Real-time congestion awareness
- Weather Integration — Journey planning with weather context
- AQI Integration — Air quality indicators per route
- Commuter Intelligence — Smart strategy cards (fastest, cheapest, balanced)
- Bilingual UI — English and Telugu (తెలుగు) with 180+ station translations
- Offline Routing — On-device computation, no backend required

### Known Limitations

- Route coverage may continue improving as GTFS data is updated.
- Analytics are in active development; some area scores are modelled estimates.
- Some mobility insights are experimental and subject to change.
- RidePool matching operates on simulated demand in this beta release.
